# end-to-end-ml-project-ml-internship


## Overview

This project was completed as part of a Machine Learning Internship. The objective was to analyze a real-world restaurant dataset and apply machine learning techniques to solve business-oriented problems including rating prediction, cuisine classification, and location-based analysis.

The project demonstrates the complete data science workflow, from data preprocessing and feature engineering to model development, evaluation, and insight generation.

---

## Project Objectives

* Predict restaurant ratings using machine learning models
* Classify restaurants based on cuisine information
* Analyze restaurant distribution using geographical data
* Extract actionable insights from real-world datasets

---

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## Task 1: Restaurant Rating Prediction

### Objective

Build machine learning models to predict restaurant ratings using restaurant attributes.

### Workflow

* Data cleaning and preprocessing
* Handling missing values
* Encoding categorical variables
* Feature engineering
* Model training and evaluation

### Models Used

* Linear Regression
* Decision Tree Regressor

### Results

| Model                   | Performance |
| ----------------------- | ----------- |
| Linear Regression       | R² = 0.20   |
| Decision Tree Regressor | R² = 0.90   |

### Key Findings

* Decision Tree Regressor significantly outperformed Linear Regression.
* Restaurant ratings are influenced by non-linear relationships.
* Customer votes, price range, online delivery, and table booking features strongly impact ratings.

---

## Task 2: Cuisine Classification

### Objective

Develop a classification model to predict restaurant cuisine categories.

### Workflow

* Cuisine preprocessing
* Feature encoding
* Classification model development
* Performance evaluation

### Challenges Identified

* Multi-label cuisine data
* Class imbalance
* Similarity between cuisine categories
* High-cardinality categorical features

### Key Findings

* Popular cuisines were predicted more accurately than rare cuisines.
* Data imbalance affected classification performance.
* Multi-cuisine restaurants increased prediction complexity.

---

## Task 3: Location-Based Analysis

### Objective

Analyze restaurant distribution and performance based on geographical information.

### Workflow

* Location data cleaning
* Latitude and longitude analysis
* City-wise aggregation
* Visualization and insight generation

### Key Findings

* Restaurants are concentrated in major cities.
* Restaurant density does not necessarily imply higher ratings.
* Price range varies significantly across locations.
* Customer preferences and cuisine popularity differ geographically.

---

## Business Insights

* Customer engagement (votes) strongly influences restaurant ratings.
* Service-related features contribute to better customer satisfaction.
* Location plays an important role in restaurant performance.
* Geographical analysis helps identify market concentration and growth opportunities.
